# Karachi Urban Heat Island (UHI) Predictive Simulation
## Comprehensive Project Report

### 1. Introduction and Original Dataset
The objective of this project was to develop a predictive model and interactive simulation tool to analyze the Urban Heat Island (UHI) effect in Karachi. The foundation of this project is the `Karachi_UHI_Data_2018_2025_Final.csv` dataset, which contains spatial pixel data capturing key environmental variables from 2018 to 2025. 

The primary target variable for the predictive model is **LST (Land Surface Temperature)**. 
The input features driving the temperatures included:
* **NDVI (Normalized Difference Vegetation Index)**: Represents the density of green vegetation.
* **NDBI (Normalized Difference Built-up Index)**: Indicates the density of concrete and built-up urban areas.
* **Albedo**: Reflects the fraction of solar energy reflected from the Earth's surface (often linked to the "Cool Roofs" concept).
* **NDWI (Normalized Difference Water Index)**: Represents the moisture content in the soil/surface.

### 2. Exploratory Data Analysis (EDA) & Preprocessing
Before modeling, the dataset underwent several preprocessing steps:
* **Cleaning**: Irrelevant metadata columns (like `system:index` and `.geo`) generated by Google Earth Engine were dropped. Any rows with missing values were also removed to prevent mathematical errors during training.
* **Correlation Analysis**: A correlation matrix heatmap (`correlation_matrix.png`) was generated to establish baseline relationships. For instance, this confirms the inverse relationship between vegetation (NDVI) and temperature (LST), as well as the positive correlation between urbanization (NDBI) and temperature.
* **Feature Scaling**: Because machine learning models like Neural Networks and Support Vector Machines are highly sensitive to the scale of input data, the features were normalized using a `StandardScaler`. This scaled representation was saved as `scaler.joblib` so that new inputs from the frontend simulation could be scaled identically.
* **Train-Test Split**: The data was split into an 80% training set and a 20% testing set to objectively evaluate the models on unseen data.

### 3. Model Training, Evaluation, and Selection
To find the most accurate predictor of Land Surface Temperature, four different machine learning regressors were trained: Random Forest, XGBoost, Support Vector Regressor (SVR), and Multi-Layer Perceptron (MLP Neural Network).

The models were evaluated using three primary metrics: **RMSE** (Root Mean Squared Error), **MAE** (Mean Absolute Error), and **R²** (Coefficient of Determination). 

The results were as follows:
* **Random Forest**: RMSE = 2.2501, MAE = 1.7423, R² = 0.6882
* **XGBoost**: RMSE = 2.2336, MAE = 1.7261, R² = 0.6928
* **SVR**: RMSE = 2.1955, MAE = 1.6870, R² = 0.7032
* **MLP**: RMSE = 2.1835, MAE = 1.6922, R² = 0.7064

**Model Selection**: The **Multi-Layer Perceptron (MLP)** was selected as the final production model. It outperformed the tree-based models and the SVR, securing the lowest error margins (RMSE of ~2.18) and the highest ability to explain the variance in the data (R² of ~0.706). MLP's complex hidden layers make it particularly adept at capturing the non-linear, interacting dynamics between albedo, urbanization, and vegetation. The trained model was serialized and saved as `best_model.joblib`.

### 4. Backend Development (FastAPI)
The inference engine was hosted on a high-performance **FastAPI** backend (Python). 
The backend serves two primary REST API endpoints:
1. `GET /api/baseline`: Filters the dataset for the most recent year (2025) and returns a subset of coordinates (latitude, longitude) and their baseline LST. This provides the frontend with the initial map data.
2. `POST /api/simulate`: The core simulation endpoint. It receives JSON payloads from the frontend containing the user's slider adjustments (`delta_ndvi_percent`, `delta_albedo`, `delta_ndbi_percent`). 
    * It dynamically manipulates the baseline dataframe, applying the percentage changes to the raw features (e.g., adding +20% to the NDBI column).
    * It passes these modified features through the `StandardScaler` and feeds them to the loaded MLP `best_model.joblib` to predict the *new* Land Surface Temperatures.
    * It returns the modified temperatures back to the frontend to update the heatmap.

### 5. Frontend Development (React & Leaflet)
The user interface was built using **React (via Vite)** and styled with **TailwindCSS** to create a sleek, professional dashboard. 
* **Interactive Map**: Built utilizing `react-leaflet`. It dynamically loops through the thousands of spatial points returned by the backend and renders them as a heatmap over Karachi. The dots are color-coded based on a custom colormap, moving from soft yellows (< 20°C) up to deep reds (> 45°C).
* **Simulation Sliders**: Three distinct sliders were implemented allowing users to heavily tweak the environment:
  * Vegetation (NDVI) ranging from -100% to +100%.
  * Cool Roof Coverage (Albedo) ranging from 0% to 100%.
  * Urbanization (NDBI) ranging from -100% to +100%.
* **Policy Impact Analytics**: To bridge the gap between raw data and actionable insights for policymakers, an analytics panel was introduced. Upon running a simulation, the frontend calculates the difference between the baseline average temperature and the newly simulated average temperature. It then translates this delta into plain text—for instance, explaining how a 1.5°C drop could result in an estimated ~6% reduction in peak cooling energy demand, framing the mathematical output around human health and urban planning benefits.

### Conclusion
By unifying Earth observation data, deep learning, and an interactive web interface, this project successfully provides a tangible, real-time environment for exploring how strategic greening and infrastructure changes can directly combat the Urban Heat Island effect in Karachi.
